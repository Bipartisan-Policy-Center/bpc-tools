# AI in the Workforce poll embeds (BPC x PF Global)

Hosted files for the poll's WordPress Custom HTML blocks: `poll-embed.js`, `poll-embed.css`, and `poll_data.json`. Each block loads these with a `?v=` version query; bump it on every deploy.

**`poll_data.json` currently holds PLACEHOLDER numbers** (invented, for a staging test). The real data is embargoed until the poll publishes on December 1, 2026, and must not be committed here before then.

Source and build scripts live in the BPC analytics workspace (`work/2026-11_ai-poll-wp-elements`, `build_dist.py`).
